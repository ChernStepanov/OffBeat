# OffBeat: покрытие данными NISAR для трёх демо-зон

Проверено 2026-11-14 только через публичные каталоги (CMR, ASF Search, Earth Search STAC). Без логина, файлы данных не скачивались.

Обозначения: **[V]** проверено запросом к каталогу или первоисточнику; **[I]** вывод или интерпретация, запросом не подтверждено.

## 0. Общее о NISAR

| Что | Значение |
|---|---|
| Коллекции L2 (CMR, провайдер ASF) [V] | `NISAR_L2_GCOV_{BETA_V1, PROVISIONAL_V1, V1}`, `NISAR_L2_GUNW_{…}`, `NISAR_L2_GSLC_{…}`, плюс L1 RSLC/RIFG/RUNW/ROFF, L2 GOFF, L3 SME2. Коллекция без суффикса зрелости (`_V1`) означает VALIDATED |
| Concept ID [V] | GCOV: BETA `C3622214170-ASF`, PROV `C2854338529-ASF`, VAL `C3622241360-ASF`. GUNW: BETA `C2850261892-ASF`, PROV `C2854335566-ASF`, VAL `C3622247503-ASF`. GSLC: BETA `C2850259510-ASF`, PROV `C2854332392-ASF`, VAL `C3622244601-ASF` |
| Первые публичные данные [V, nisar-docs.asf.alaska.edu/availability-overview] | 2026-01-23: 25 тестовых продуктов BETA. 2026-02-27: массовый релиз BETA (подмножество съёмок 2025-10-17…2026-01-20, до 8 съёмок на трек, без полной калибровки) |
| PROVISIONAL [V, там же] | Релиз 2026-07-20. Съёмки с 2026-06-17 по ~2026-10-23. Для отдельных кадров есть более длинные ряды (видно ниже: Каракас и Мехико с 2025-11) |
| VALIDATED [V, там же] | Релиз 2026-11-06. Все L-band съёмки начиная с 2026-10-21. Более ранние данные переобработают в 2027 г. |
| Постоянная дыра в данных [V, там же; видна в датах] | 2026-07-27T22:03Z … 2026-08-10T00:55Z. Пары GUNW в этом месте 24-дневные (напр. 20260723–20260816) |
| Повтор [V, по датам] | 12 сут. на один трек/кадр. С учётом всех треков (A+D) на точку приходится 3–6 сут. |
| Диапазон [V/I] | Всё найденное в ASF/CMR относится к L-band. S-band распространяет ISRO (Bhoonidhi), в ASF его нет [V, docs]. HH/HV есть, VV/VH нет (кроме редких режимов `NASV`/`SHSV`) |
| Объёмы в каталоге на 2026-11-14 [V] | GCOV: BETA 23 527, PROV 163 672, VAL 14 486. GUNW: BETA 10 217, PROV 94 150, **VAL всего 140**: валидированные GUNW почти не выпущены |

**Расшифровка имени файла [I]** (по виду имён; официальная спецификация JPL D-102255 не читалась):
`NISAR_L2_PR_GCOV_<цикл>_<трек>_<A|D>_<кадр>_<режим>_<пол>_<A|M>_<старт>_<конец>_<CRID>_N_<F|P>_J_001`

* `режим`: ширина полосы в МГц для частот A и B. `4005` = 40+5 МГц, `2005` = 20+5 МГц, `4000`/`2000` = только частота A.
* `пол`: 2 символа на частоту A, 2 на частоту B. `DH` = HH+HV, `SH` = только HH, `QP` = quad, `NA` = нет данных.
* `F`/`P`: полный или частичный кадр.
* GUNW: `..._GUNW_<цикл1>_<трек>_<dir>_<кадр>_<цикл2>_<режим>_<пол>_<t1>_<t1e>_<t2>_<t2e>_...`, пара соседних съёмок (12 сут.). GUNW строятся только по HH (`SH`).

Скрипт сводок, `q.py`, лежит в рабочей папке и в репозиторий не входит. Он делает постраничные запросы к CMR (`short_name` + `bounding_box`, `page_size=2000`) и группирует по трек/кадр/режим/поляризация.

## 2. Обезлесение в Амазонии

### Как выбирали [V]
Сетка ячеек 0.45°×0.45° по дуге обезлесения: lon −66…−48, lat −13…−3, 720 ячеек. Для каждой считали GCOV (BETA+PROV+VAL), число уникальных дат и максимум дат на одном треке.

* Типичная ячейка в Пара/Рондонии/Мату-Гросу: 19–25 уникальных дат по всем трекам, но ≤ 9–10 на трек, все с 2026-06-17 (PROVISIONAL).
* Длинный ряд есть у **трека 045 A** (восток Пара, lon −49.5…−48.05). Там 17 дат на трек начиная с 2025-11-01.
* Максимум по сетке у трека 089 A около Tefé (AM): 27 дат. Но это почти нетронутый лес, вне дуги обезлесения.
* Индонезия как запасной вариант [V, грубо]: Риау 101.6,0.0,102.05,0.45 даёт 44+4 гранул GCOV, Центр. Калимантан 113.6,−2.6,114.05,−2.15 даёт 53+6. Оба только с 2026-06 и не лучше Пары по глубине ряда.

### Выбранный AOI: AMZ-PA, Итупиранга / Нову-Репартименту (Пара), ~50×50 км
bbox **−49.5,−5.0,−49.05,−4.55** [V]. То, что это зона активной вырубки (пастбища и остатки леса), это [I] по PRODES, ячейка не проверялась.
