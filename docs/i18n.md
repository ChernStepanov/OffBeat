# Persistent interface languages

The dashboard, research page and candidate map share English, Russian, French,
German, Italian, Spanish, Portuguese, Japanese and Arabic. The selector uses native
language names and stores its choice in `offbeat.language.v1`. This preference is
independent of the experimental workspace layout. Arabic uses RTL document flow;
map controls, plots, numeric coordinates and source IDs retain their own direction.
Japanese and Arabic use native system font fallbacks.

`locales/source-pairs.json` is an ordered English/Russian source index. Its order
must remain stable: catalogue IDs are `k` plus the entry's zero-based index.
All nine checked-in catalogues contain 845 entries. Numeric values and dates are
substituted through validated placeholders; translation never modifies measured
data, exports, scientific identifiers or user messages.

Catalogues were generated offline with Groq GPT-OSS models, with manually reviewed
navigation, common controls and numeric-sign overrides in
`locales/reviewed-overrides.json`. No translation API runs when browsing or changing
languages. Catalogues still work when Groq is unavailable. These translations have
not received a full native-speaker scientific review. Unknown dynamic text and some
long research/source descriptions remain in their original language rather than
being translated live or having their scientific meaning guessed. This feature
translates the interface, not every external document, map label or dataset.

To append recognized source strings, run `node scripts/extract_locales.cjs`, review
the additions, then run `python3 -m scripts.build_locales` with `GROQ_API_KEY` set on
the server or in ignored `.env`. Generation resumes completed entries and defaults
to GPT-OSS 120B. The
optional `OFFBEAT_TRANSLATION_MODEL` only affects this offline tool. Unsupported
models fail immediately. Never commit the credential.

Before committing, run `python3 -m unittest scripts.test_locales` and
`node scripts/version_assets.mjs`. Update `locales/manifest.json` after extending
sources. Test real pages for wrapping, RTL and language persistence: structural
catalogue validation alone cannot establish translation quality.
