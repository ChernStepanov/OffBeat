# Датированные RGB-снимки

`python scripts/optical.py` ищет сцены Sentinel-2 L2A по датам NISAR
в пределах ±15 календарных дней UTC. Выбор — минимум облачности целого
тайла, затем близость к дате. Источник — публичный Earth Search, без Earthdata.
Облачность над участком не оценена; выбранный снимок не обязательно чистый.

`python scripts/crop_optical.py` читает только окна B04/B03/B02 из удалённых COG
через rasterio/GDAL HTTP Range. Перепроекция — EPSG:4326, строго в `grid.bbox`.
Длинная сторона PNG — 256 пикселей; размеры сторон учитывают широту участка.
Нативный nodata прозрачен. Сцены повторно не обрабатываются, если совпадают
версия обработки, границы, RGB URL и SHA-256 локального PNG.
`--site amazon` ограничивает участок, `--refresh` принудительно пересобирает.

Для всех снимков применяется одна шкала: отражательная способность 0..0.3,
gamma 2.2, без индивидуального растяжения гистограммы. Это отображение RGB,
не количественный анализ изменения поверхности.

У legacy-коллекции `sentinel-2-l2a` противоречивые метаданные BOA offset:
[обсуждение поставщика](https://github.com/Element84/earth-search/discussions/26).
Если `earthsearch:boa_offset_applied` равен `true`, поправка уже внесена в DN
и второй раз не вычитается, даже если `raster:bands.offset` равен −0.1.
При отсутствии подтверждающего флага скрипт отказывается строить изображение.
Это правило по метаданным поставщика; независимой радиометрической валидации нет.
В квитанции сохранены объявленный offset, применённый offset, scale и флаг.

В `data/<site>/optical/index.json` каждая дата NISAR сохраняет выбранную сцену.
После вырезки добавляются `crop_status`, `crop_error` и `scene.render`:
PNG, границы, CRS, размеры, шкала, доля валидных пикселей, SHA-256 и нативные окна.
Одинаковые сцены используют один PNG. Ошибка вырезки записывается явно;
скрипт завершится с ненулевым кодом. Доля валидных RGB-пикселей не означает
долю ясного неба: облака и тени не маскируются.

Селектор над картами переключает подготовленные даты и «Esri mosaic (dates vary)».
Auto выбирает ближайшую подготовленную сцену к `since` выбранной точки,
а если `since` отсутствует — к последней дате NISAR. Это привязка к дате
кандидата изменения, не к точному времени установленного события.
Ручной выбор сохраняется при смене точки; при смене участка возвращается Auto.
Дата, облачность тайла и ID сцены показаны рядом с картами.

RGB накладывается только внутри границ участка. Снаружи и через прозрачные
пропуски видна контекстная мозаика Esri. При ошибке PNG или недоступном индексе
интерфейс явно сообщает о переходе к контексту. Запоздалый ответ от предыдущего
участка не меняет текущую карту.

Проверки:

```bash
python -m pytest scripts/test_crop_optical.py -q
python scripts/optical.py --self-test
node scripts/test_optical.mjs
node scripts/test_data.mjs
node scripts/test_search.mjs
```

Contains modified Copernicus Sentinel data (2025–2026).

На 14 ноября 2026 года подготовлены 27 уникальных PNG: Мехико — 17,
Амазония — 5, Каракас — 5. Они покрывают все 41 выбранную дату NISAR;
каждый файл меньше 152 КБ. Визуально просмотрены все 27 вырезок.
В браузере проверены три участка, ручная смена даты, возврат к мозаике
и Auto для кандидата Амазонии. Облака видны на части вырезок и не удалялись.
