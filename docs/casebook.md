# Проверка изменения: публичный маршрут и карточка доказательств

Вход: **Investigate a change / Исследовать пример изменения** в приветствии
или над картой. Четыре шага: место, радар и звук, независимые данные, решение.
Существующий обзорный тур и свободная навигация остаются доступны.

Основной пример — AMA r5 c15: падение HV между 23 августа и 4 сентября.
Рядом доступны два контраста: видимая расчистка AMA r4 c14, непригодная для
оценки детектора из-за недостатка истории «до», и AMA r28 c1 с вероятным
ложным выделением устойчивого изменения. Это ретроспективные разборы,
не независимые положительные/отрицательные тестовые события.

`data/cases/amazon-v1.json` воспроизводится из сохранённых измерений и разборов:

```sh
python3 scripts/build_casebook.py
node scripts/test_evidence.mjs
```

В файле закреплены SHA-256 входов, исходные даты/URL/хеши оптики, индексы
точек и границы допустимых выводов. Изображения показываются в одинаковом
географическом фрагменте вокруг координаты; это увеличенное превью, а не
новые данные высокого разрешения. Ясность AOI не выдаётся за качество точки.
Кнопки «до/после» выбирают SAR-наблюдения, а не дату события. Звук запускается
только по нажатию и не выдаётся за дополнительное научное подтверждение.

Карточку можно открыть для любой выбранной точки. Вне подготовленного
разбора статус — «независимой проверки нет». Выгрузка JSON содержит ряд
HH/HV, соседский фон, качество, происхождение данных, интерпретацию,
ограничения и ссылку. GeoJSON содержит **Point**, а не предполагаемый контур
события. Ссылка кодирует site/sample/date/case/step и восстанавливает
состояние после стартовой загрузки карты. Ошибочная дата или индекс
отклоняются; разбор другой точки не переносится на выбранную.

Для демо:

```
?site=amazon&case=amazon-hv-step&sample=175&date=2026-09-04&step=1
```

Карточка не делает завершённой независимую научную проверку. Пригодных
положительных событий, слепых отрицательных контролей и независимых
тестовых групп по-прежнему 0; precision, recall и FPR неизвестны.
Следующий необходимый научный шаг — дополнительные NISAR-даты/участки
с независимо ограниченным временем события и валидными наблюдениями
до/после, затем независимая разметка без настройки на тестовых событиях.
