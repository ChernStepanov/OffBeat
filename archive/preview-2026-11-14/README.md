# Архив проверки GLAD и RGB

Сохранены исходные материалы эксперимента из коммита `61979b2` ветки
`strongf/real-preview-analysis`: ответы источников, RGB/SCL, ручные разборы
и результаты положительного контроля. Файлы скопированы без изменений.

Это исторический эксперимент с прежней версией классификатора и подготовки
оптики, а не проверка текущего релиза. Относительные пути внутри JSON относятся
к исходному репозиторию. Рабочий сайт этот архив не загружает.

Главный результат: среди пяти точных пересечений с GLAD не получено пригодного
набора независимых положительных случаев с достаточной радарной историей до
события. Работоспособность детектора и полнота обнаружения не доказаны.
Дату публикации GLAD нельзя автоматически считать датой расчистки.

устаревшие скрипты и рабочие индексы старой ветки не возвращались.
